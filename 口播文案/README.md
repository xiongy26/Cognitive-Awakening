## 写作规则

生成新节次文案时，**必须先阅读规则文件**：
`.ai_rules/rules/口播文案生成规则.mdc`

核心要点速览：

**六拍结构（60 秒）**：共鸣钩子 (0-6s) → 陈述事实 (7-20s) → 反差金句 (21-33s) → 机制解释 (34-45s) → 落地结论 (46-55s) → 悬念收尾 (56-60s)

**五条铁律**：

1. **事实先行，比喻收尾** — 涉及知识必须先给真实的名称+功能+年代/数据，比喻只能放在事实之后
2. **先共鸣，后解释** — 第 1 秒必须是具体日常场景
3. **把观众从自责里捞出来** — 全片一次"原来这不是我的错"的转向
4. **抽象概念要有人物化载体** — 但载体必须依附在已陈述的事实上
5. **一句话一件事** — 数字最多 3 个

**术语红线**：下丘脑不属于三重大脑中的任何一块（属间脑，管体温/饥饿口渴/睡眠节律/内分泌）。三重脑请用脑干、边缘系统、前额叶皮层。

**字数**：240-260 字

每个节次产出独立文件 `<节次编号>_<章节名>.md`，固定包含：标题备选、正文口播稿、配套画面、备选开头、素材出处、术语红线、可复用素材。**不要写"本版修订记录"小节**——版本迭代过程留在对话里，不进交付文件。写完后同步更新本文件的进度表。
